    Cara setup webhook Discord
    1 Buka server Discord → klik channel → klik Pengaturan Channel
    2 Tab Integrasi → Webhooks → New Webhook
    3 Beri nama, pilih channel, klik Copy Webhook URL
    4 Tempel URL di kolom Webhook URL di atas
    5 Discord Settings → Advanced → aktifkan Developer Mode
    6 Klik kanan role → Copy Role ID → tempel di kolom Role ID
